# MealCircle – From Leftovers to Lifesavers 🍽

MealCircle is a social-impact web application designed to reduce food waste by connecting food donors with people and organizations in need.

## Features
- Donate leftover food from events, restaurants, and homes
- View available donations in real-time
- Firebase real-time database integration
- Analytics dashboard for donation insights

## Tech Stack
- Python
- Streamlit
- Firebase Realtime Database
- Pandas
